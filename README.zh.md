### 🛡️ 工程哲学与核心技术领域

<details open>
<summary><b>⚔️ 进攻性安全、移动端逆向工程与破坏性 QA</b> <i>(点击展开/折叠)</i></summary>
<br/>

- **业务逻辑漏洞挖掘与利用**:
  - 针对高并发金融支付网关与异步数据对账引擎，深入审计并进行受控利用：深度挖掘 **业务逻辑漏洞 (Business Logic Flaws)**、参数篡改、IDOR 越权、条件竞争 (Race Conditions) 以及客户端校验绕过。
- **移动安全与底层二进制插桩**:
  - 利用 **Frida** 实现运行时动态 Hook，使用 **Il2CppDumper** 还原原生符号与代码结构，深入 Dalvik/ART 运行时机制与反编译分析（JADX、Ghidra）。
  - 基于 Magisk (`cert-fixer`) 自动化注入系统级 CA 根证书，绕过 SSL/TLS Pinning 双向认证，并通过 Burp Suite Professional 执行透明 MITM 流量分析与修改。
  - 为企业级网络流量分析工具（包括 Fiddler Everywhere）独立研发内存字节码补丁与运行时自动化套件。
- **破坏性质量保证与极限模糊测试 (Destructive QA)**:
  - 在生产发布前主动模拟恶意对抗场景：通过高并发异步重放实现双花与资金重复入账攻击、浮点数舍入精度缺陷利用，以及分布式缓存状态竞争破坏。
</details>

<details>
<summary><b>🏢 企业级核心系统与高可用 ERP 架构</b> <i>(点击展开/折叠)</i></summary>
<br/>

- **Saargo Spa 核心企业架构**:
  - 全面主持企业级核心 ERP 系统架构设计与生产运维（技术栈：PHP 8.3、SQL Server、Python）。
  - 研发具备严格 ACID 事务保证、高并发执行、极致索引优化及自动对账结算的业务关键型后端。
- **牢不可破的后端韧性 (Backend Resilience)**:
  - 在接口层与数据库持久层严格践行零信任 (Zero-Trust) 校验机制。
  - 构建具备幂等性保证的 API 接口、服务端有限状态机 (FSM) 及异步消息队列系统（Redis、RabbitMQ），彻底免疫畸形与恶意篡改报文。
</details>

<details>
<summary><b>⛓️ 区块链底层架构与去中心化 P2P 协议</b> <i>(点击展开/折叠)</i></summary>
<br/>

- **Foxycoin 核心架构师**:
  - 主导并实施自主加密货币的研发：深度优化 P2P 网络底层守护进程、共识机制、区块验证算法，并编译原生跨平台客户端钱包（Linux/Windows）。
- **密码学隐私协议研究**:
  - 基于 CryptoNote 及其衍生协议，深入实现并审计环签名 (Ring Signatures)、隐匿地址 (Stealth Addresses) 及机密交易 (RingCT) 技术。
</details>

<details>
<summary><b>🧪 计算科学、硬件嵌入式与本地化 AI 智能体</b> <i>(点击展开/折叠)</i></summary>
<br/>

- **硬核计算机科学与算法建模**:
  - 研发动态寻路算法、实时高精度物理仿真引擎、数值分析计算与计算几何算法。
- **超低延迟嵌入式物联网 (IoT)**:
  - 针对微控制器（ESP32、STM32、Arduino）编写底层 C/C++ 固件，利用 WebSockets/MQTT 构建极低延迟的自主传感器通信链路。
- **自主智能体与本地离线推理**:
  - 研发并部署多智能体协作流水线、检索增强生成 (RAG) 体系，基于本地基础设施驱动私有知识库 LLM 推理调度（*YuyinODS*）。
</details>
